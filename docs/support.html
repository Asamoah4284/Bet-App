Common topics

  • Notifications not arriving — check OS permission and Reminders settings; use a production/preview build (not Expo Go) for remote push
  • Shield not blocking — requires a native build and system VPN / Network Extension permission
  • Streak reset — daily reflection must be confirmed; missing more than one day resets the streak
